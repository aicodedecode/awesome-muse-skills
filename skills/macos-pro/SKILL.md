# macOS Pro

## Overview

macOS rewards users who learn its layers: the GUI for discovery, keyboard for speed, Terminal and Shortcuts for automation.

Most Mac users touch 10% of the OS. The pro 10% — Spotlight fluency, Finder mastery, Shortcuts automation — compounds daily.

This skill covers the setup, habits, and maintenance that keep a Mac fast and frictionless for years.

## When to use

- Setting up a new Mac for productive work
- Speeding up Finder, window, and app-switching workflows
- Automating repetitive macOS tasks with Shortcuts or shell
- Troubleshooting a slow or cluttered Mac
- Learning macOS after switching from Windows or Linux

## Core concepts

- **Spotlight as command line.**
  Cmd+Space: launch apps, open files, do math, convert units, search the web. The fastest way to do almost anything.
- **Finder mastery.**
  Column view for navigation, Quick Look (Space) for previews, tags for cross-folder organization, smart folders for saved searches.
- **Mission Control and Spaces.**
  Multiple desktops per workflow (communication, deep work, admin). Three-finger swipe or Ctrl+arrows to move; fullscreen apps get their own Space.
- **Trackpad gestures.**
  Learn the core set: swipe between spaces, Mission Control, App Expose, pinch for Launchpad. Gestures beat menu-diving.
- **Shortcuts app.**
  Visual automation: file operations, text transforms, multi-app sequences. Runs on schedule, from the menu bar, or via Siri.
- **Terminal basics.**
  Even GUI-first users benefit: Homebrew for installs, simple shell commands for batch file ops, ssh for remote work.
- **System Settings fluency.**
  Know where things live: trackpad, keyboard (key repeat, modifier remapping), notifications, Focus modes, login items.
- **Time Machine.**
  Set-and-forget versioned backups to an external drive. The single most important 'pro' habit — unglamorous, irreplaceable.

## Practical workflow

1. **Run initial setup deliberately.**
   Apple ID, iCloud settings (decide what syncs), FileVault on, Firewall on, Time Machine drive connected.
2. **Configure input first.**
   Key repeat to fast, Caps Lock remapped if desired, trackpad gestures enabled, hot corners set (or disabled if accidental).
3. **Master Spotlight week one.**
   Force yourself: Cmd+Space for everything for a week. App launching via Dock becomes the slow way.
4. **Tame Finder.**
   Column view default, status bar and path bar on, tags defined (3-7), smart folders for active projects and recent downloads.
5. **Set up Spaces.**
   2-4 desktops with assigned roles; put communication apps on one Space so they stop interrupting deep work.
6. **Build 3 Shortcuts.**
   Start with real annoyances: rename-and-file downloads, resize images, start-a-focus-session. Automate pain, not hypotheticals.
7. **Install via Homebrew.**
   One package manager for CLI tools and casks. Script your setup so a new Mac is 30 minutes, not a weekend.
8. **Schedule maintenance.**
   Monthly: review login items and storage, update apps, verify Time Machine. Yearly: clean installs only if truly needed.

## Common pitfalls

- **Dock-diving.**
  Hunting icons in the Dock instead of Spotlight. Slower every single time, hundreds of times a day.
- **Desktop as storage.**
  Files on the Desktop slow Finder and bury work. Desktop = temporary inbox, cleared weekly.
- **Ignoring Time Machine.**
  No backup until the drive dies. Plug in a drive, turn it on, forget it — until you need it desperately.
- **Notification chaos.**
  Every app notifying by default. Ruthlessly prune: most apps get no banners, no sounds, batched delivery.
- **Login item creep.**
  Dozens of helpers launching at boot, slowing everything. Audit login items quarterly.
- **Never learning Terminal.**
  GUI-only users hit walls on batch operations. Ten shell commands unlock enormous leverage.
- **iCloud confusion.**
  Not knowing what's synced vs. local. Decide deliberately per folder; don't discover it during an outage.
- **Skipping updates forever.**
  Security updates delayed for months. Enable automatic security updates; schedule feature updates.
