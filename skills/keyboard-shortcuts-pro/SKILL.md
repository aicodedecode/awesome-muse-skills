# Keyboard Shortcuts Pro

## Overview

Every mouse round-trip costs seconds and breaks flow. Keyboard-first users never leave the home row.

The skill isn't memorizing 500 shortcuts — it's the 20% covering 80% of actions, plus custom bindings for personal frequent actions.

Patterns rhyme across OS and apps: learn universals once, benefit everywhere.

A keyboard launcher replaces most mouse navigation: apps, files, commands, math, windows — one hotkey.

## When to use

- Setting up a new computer or switching OS
- Feeling slow in main apps (editor, browser, email, terminal)
- Reducing repetitive strain from mouse overuse
- Onboarding to keyboard-driven tools (vim, tmux, tiling WMs)
- Speeding up repetitive multi-step computer tasks

## Core concepts

- **Universal patterns first.**
  Copy/cut/paste/undo, save, find, select-all, close/new/reopen tab, app switching, screenshots. Learn once, use everywhere.
- **The 80/20 set per app.**
  Your 10-15 most-used actions per core app. Depth in main apps beats breadth across all apps.
- **Learn in context.**
  Third time mousing the same action -> look up its shortcut, use deliberately for a week. Need-driven learning sticks.
- **Custom bindings.**
  Remap awkward defaults; create hotkeys for personal high-frequency actions (task quick-add, multi-step macros).
- **Launcher as universal interface.**
  One global hotkey for launching apps, opening files, running commands, calculations, window management.
- **Leader keys and mnemonics.**
  Prefix-key sequences scale to hundreds of commands without finger gymnastics (vim, tmux, launcher workflows).
- **Consistent setups.**
  Sync/export bindings and launcher config. Rebuilding muscle memory per machine is a hidden tax — version-control it.
- **Terminal shortcuts.**
  If you live in a terminal: Ctrl-A/E/K/U, Alt-B/F, history search, multiplexer keys. As valuable as any app's shortcuts.

## Practical workflow

1. **Audit mouse usage.**
   One typical day: notice repeated mouse actions in main apps. Top 10 = highest-ROI shortcuts to learn.
2. **Drill the universals.**
   Cross-app patterns until automatic — about a week of deliberate use. Eliminates surprising amounts of mousing.
3. **Master one app at a time.**
   Most-used app first: 10-15 essentials. Visible cheat sheet for two weeks, then remove it.
4. **Set up a launcher.**
   Global hotkey; learn app launching, file search, clipboard history, calculations, window management.
5. **Create 3-5 custom bindings.**
   Global capture hotkeys + macros for multi-step repeats. Only for proven-frequent actions.
6. **Practice deliberately.**
   Two weeks: catch yourself mousing a known action -> undo, redo via keyboard. Annoying, then automatic.
7. **Maintain a cheat sheet.**
   One note: custom bindings + per-app essentials. Review on new machines; prune unused bindings.
8. **Remap Caps Lock.**
   Caps Lock as Ctrl/Escape is the classic comfort upgrade. Your hands, your rules.

## Common pitfalls

- **Learning everything at once.**
  200 shortcuts in a weekend = zero retained. Gradual, need-based learning wins.
- **Ignoring the launcher.**
  Single highest-ROI keyboard tool. Launcher hotkey in muscle memory before anything else.
- **Suffering awkward defaults.**
  Finger-twisting defaults when remapping takes 30 seconds. Move modifiers to comfortable keys.
- **No cheat sheet while learning.**
  Pure memory during the fragile phase slows adoption. Visible reference for two weeks, then remove.
- **Mouse relapse under pressure.**
  Deadlines trigger old habits. Accept it; return to keyboard-first after the crunch.
- **Over-customization.**
  Fifty bindings you can't remember < five you use daily. Add only for proven-frequent actions.
- **Inconsistent machines.**
  Different bindings on work vs. home = relearning twice. Sync configs or mirror manually.
- **Skipping ergonomics.**
  Keyboard-first with bad posture still hurts. Shortcuts reduce mouse strain; they don't fix a bad setup.
