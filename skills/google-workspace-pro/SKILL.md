# Google Workspace Pro

## Overview

Google Workspace is the default productivity suite for millions: Gmail, Drive, Docs/Sheets/Slides, Calendar, Meet — deeply integrated and collaboration-first.

Pro users exploit the integration: email-to-task, calendar-from-email, shared drives, templates, and keyboard-first operation in every app.

This skill covers the cross-app workflows and settings that turn Workspace from 'free email' into a professional operating system.

## When to use

- Living in Gmail/Drive/Docs daily for work or school
- Setting up Workspace for a team or small business
- Speeding up email, document, and calendar workflows
- Organizing shared drives that don't become chaos
- Collaborating on docs/sheets with many people

## Core concepts

- **Gmail power use.**
  Keyboard shortcuts on, multiple inboxes or tabs configured, filters + labels (not folders), templates, scheduled send, confidential mode where apt.
- **Drive organization.**
  My Drive (personal) vs. Shared drives (team-owned). Star key items, use shortcuts not copies, Priority/workspaces for active work.
- **Docs/Sheets mastery.**
  Styles + outline, suggesting mode for edits, version history + named versions, Explore, connected sheets, data validation and filters.
- **Calendar integration.**
  Events from Gmail auto-added, appointment schedules, working hours + location, layered calendars, find-a-time for groups.
- **Meet fluency.**
  Companion mode, breakout rooms, polls/Q&A, recording + transcripts, dial-in. Test audio/video before important calls.
- **Search across Workspace.**
  Drive search operators (`type:`, `owner:`, `before:`), Gmail operators (`from:`, `has:attachment`, `older_than:`). Search beats folders.
- **Templates and building blocks.**
  Docs templates, Sheets templates, smart chips (@-mentions for people/files/dates), dropdowns and checklists in Docs.
- **Admin basics.**
  For Workspace admins: users/groups/OUs, 2SV enforcement, data retention, shared drive permissions, security dashboard.

## Practical workflow

1. **Configure Gmail.**
   Shortcuts on, undo-send 30s, filters for noise (labels + skip inbox), 2-3 inbox tabs, templates for repeats, signature.
2. **Organize Drive.**
   Move team files to Shared drives (survive departures). Star active work. Use shortcuts instead of duplicate copies.
3. **Set up Calendar.**
   Layers (work/personal/team), working hours, appointment schedules if client-facing, Gmail event auto-add on.
4. **Learn the operators.**
   Gmail + Drive search operators. Practice until searching beats browsing folders.
5. **Template the repeats.**
   Docs/Sheets templates for reports, invoices, trackers. Smart chips for people, files, dates.
6. **Tune collaboration.**
   Suggesting mode default for shared docs, comment + assign for action items, named versions before big changes.
7. **Secure the account.**
   2-Step Verification (security key preferred), review third-party access, check account activity periodically.
8. **If admin: lock down basics.**
   Enforce 2SV, organize OUs/groups, set retention policies, audit sharing settings and external sharing.

## Common pitfalls

- **Labels ignored, inbox chaos.**
  Gmail without filters/labels/shortcuts is just a pile. The 30-minute setup pays back daily.
- **My Drive for team files.**
  Employee leaves, their 'team' files leave too. Shared drives are owned by the team — use them.
- **Copies instead of shortcuts.**
  Ten copies of the deck diverging. Share one file; use shortcuts where it must appear twice.
- **No version discipline.**
  Editing shared docs blindly. Suggesting mode + named versions prevent 'who changed what' wars.
- **Search operators unknown.**
  Scrolling through Drive instead of `type:spreadsheet owner:me`. Operators are the fast path.
- **2SV skipped.**
  The account holding your email, files, and identity without two-step verification. Non-negotiable.
- **Over-sharing.**
  'Anyone with the link' as default for sensitive docs. Default restrictive; open deliberately.
- **Meet unprepared.**
  Joining important calls without testing audio/video. Two-minute pre-check prevents ten-minute fumbles.
