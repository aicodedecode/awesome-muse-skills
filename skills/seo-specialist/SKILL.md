## Overview

SEO specialists earn organic traffic through three pillars: technical health (crawlability, speed, structure), content relevance (matching search intent better than competitors), and authority (links and brand signals). This skill covers audits, keyword strategy, on-page optimization, link building, and the measurement that proves impact.

## When to use

- Auditing a site's SEO health
- Building a keyword strategy
- Diagnosing ranking drops
- Planning link-building campaigns
- Fixing technical issues (crawl errors, speed, indexing)
- Setting SEO goals and reporting

- Recovering from a Google core update hit
- Planning a site migration without losing rankings
- Building topical authority in a competitive niche
- Diagnosing traffic drops after updates
- Building international SEO (hreflang, ccTLDs)
- Optimizing for AI search and answer engines
## Core concepts

**The three pillars.** Technical (can search engines access and understand the site?), content (does it satisfy intent better than competitors?), authority (do others vouch for it via links?). Weakness in any pillar caps the others.

**Keyword strategy.** Map keywords to pages (one primary keyword per page), cluster by intent, prioritize by (relevance × volume × winnability). Target a mix: quick wins (low competition), core terms (medium-term), and stretch goals (long-term authority plays).

**Technical SEO.** XML sitemaps, robots.txt, canonical tags, hreflang for international, structured data, Core Web Vitals (LCP, INP, CLS), mobile-friendliness, HTTPS, clean URL structure, internal linking architecture. Crawl budget matters most for large sites.

**On-page optimization.** Title tags, meta descriptions, header hierarchy, keyword placement, image optimization, internal links, content depth, and SERP feature targeting (featured snippets, FAQs, tables).

**Link building.** Earn links through: digital PR (data studies, newsworthy content), resource link building (best-in-class guides), broken link building, HARO/journalist outreach, and partnerships. Buy links never — penalties and wasted money.

**E-E-A-T.** Especially for YMYL topics (health, finance, legal): demonstrate real expertise, named authors, citations, and trust signals. Google's quality raters reward genuinely authoritative content.


**Topical authority.** Covering a topic comprehensively across pillar and cluster content signals expertise to search engines. Measure via: keyword footprint growth in the topic, average ranking position trend, and internal link density. Authority compounds — the 50th article in a cluster ranks faster than the 5th.

**Site migrations.** The highest-risk SEO event: map every URL (redirects 1:1, no chains), preserve metadata and structured data, monitor indexation daily post-launch, and keep old sitemaps briefly. Most migration traffic losses trace to redirect gaps — audit relentlessly.

**Crawl budget optimization.** Large sites: prioritize important pages via internal linking, prune thin content, fix crawl traps (faceted navigation, infinite calendars), and monitor crawl stats.
Googlebot time is finite — spend it on pages that matter.
Log file analysis reveals what actually gets crawled versus what you assume.
**Structured data.** Schema markup for articles, products, FAQs, events, breadcrumbs, and organizations.
Enables rich results (stars, prices, FAQ dropdowns) that lift CTR 20–30%.
Validate with Rich Results Test; monitor Search Console enhancements reports.
**AI search adaptation.** Answer engines (ChatGPT, Perplexity, AI Overviews) cite sources differently: clear factual statements, quotable definitions, structured data, and topical authority.
Optimize for citation: be the clearest answer, not just the top-ranked page.
Track brand mentions in AI answers, not just traditional rankings.
## Practical workflow

1. **Audit.** Crawl the site: indexation issues, broken links, redirect chains, duplicate content, thin pages, speed issues, mobile problems, structured data errors. Prioritize by impact × effort.
2. **Keyword research and mapping.** Build the keyword universe, cluster by intent, map to existing pages, identify gaps (keywords with no good page) and cannibalization (multiple pages targeting the same keyword).
3. **Fix technical foundations.** Resolve crawl/index issues first — content can't rank if it can't be crawled. Then speed, then structured data and internal linking improvements.
4. **Optimize and create content.** Refresh underperforming pages (expand, update, improve intent match). Create cluster content for gaps. Every page: optimized on-page elements + internal links.
5. **Build authority.** Monthly link-building sprints: one linkable asset (data, tool, definitive guide) + outreach. Track referring domains (quality over quantity — one authoritative link beats fifty spammy ones).
6. **Measure and report.** Track: organic traffic, keyword rankings (by cluster), conversions from organic, Core Web Vitals, indexation health, referring domain growth. Report monthly with actions taken and next priorities.

**Audit priority order:** indexation/crawl blocks → site speed → duplicate/thin content → on-page gaps → internal linking → structured data → authority building.


**Monthly SEO routine:** 1) rank tracking review (wins, losses, new opportunities), 2) technical health check (crawl errors, speed, indexation), 3) content performance (which pages grew/declined and why), 4) link acquisition review, 5) competitor movement scan, 6) next month's priorities (impact × effort ranked).

**Technical audit framework:** crawlability (robots, sitemaps, status codes) → indexation (coverage report, canonicals) → site architecture (depth, internal links) → page experience (Core Web Vitals, mobile) → structured data → international (hreflang) → log analysis.
Prioritize by impact × effort; fix crawl-blocking issues before content tweaks.
**Link building playbook:** digital PR (data studies, newsworthy angles) → resource link building (best-of lists, tools) → broken link building → HARO/journalist requests → competitor gap analysis.
Quality over quantity — one authoritative link beats fifty directory submissions.
## Common pitfalls

- **Chasing algorithm updates.** Reacting to every update with panic changes. Build for users; stable quality survives updates.
- **Keyword cannibalization.** Multiple pages competing for the same term. Consolidate or differentiate.
- **Buying links.** Short-term gains, long-term penalties. Earn links with genuinely link-worthy content.
- **Ignoring technical SEO.** Great content on an uncrawlable site ranks nowhere. Foundations first.
- **Thin content at scale.** Publishing hundreds of low-value pages. Depth and intent-match beat volume.
- **No internal linking strategy.** Orphaned pages and wasted authority flow. Link deliberately.
- **Reporting rankings without revenue.** Rankings are a means; track organic conversions and revenue.
- **Expecting fast results.** SEO compounds over 6–12 months. Set expectations honestly; don't promise page 1 in 30 days.
- **Chasing every algorithm update.** Reacting to unconfirmed update chatter with drastic changes. Wait for confirmed, sustained impact before acting.
- **Neglecting Bing and alternatives.** Google dominates, but Bing powers significant enterprise and voice search. Basic optimization covers both — do not ignore it entirely.
- **Ignoring Search Console.** Flying blind on indexation, queries, and penalties. Weekly Search Console reviews catch problems early.
- **Thin content at scale.** Programmatic pages with no unique value. Every indexed page must earn its place — noindex or improve the rest.
