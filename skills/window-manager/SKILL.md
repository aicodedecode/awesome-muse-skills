# Window Manager

## Overview

Window management is invisible overhead: dragging, resizing, hunting, and rearranging — hundreds of micro-interruptions daily.

Tiling and layout tools eliminate it: windows snap to grids, layouts apply by hotkey, virtual desktops separate contexts.

Options range from OS built-ins (snap layouts, Spaces) to dedicated tools (tiling managers, FancyZones-style grids).

Goal: any window arrangement you use regularly achievable in under a second, keyboard-driven.

## When to use

- Constant window rearranging between tasks
- Small screens where every pixel matters
- Multi-monitor setups needing consistent layouts
- Reducing mouse-driven window dragging
- Building a keyboard-first desktop workflow

## Core concepts

- **Tiling vs. floating.**
  Tiling: windows auto-arrange in non-overlapping grids. Floating: classic overlap, manual placement. Tiling maximizes usable space; floating suits occasional dialogs.
- **Snap layouts.**
  Halves, thirds, quadrants via hotkey or drag-to-edge. The 80% solution built into modern OSes.
- **Custom grids.**
  FancyZones-style custom zones for ultrawide or multi-monitor: define once, snap forever. Design around your actual workflows.
- **Virtual desktops.**
  Separate desktops per context (code, comms, research). Window management becomes context management.
- **Hotkey layouts.**
  Your 4-6 arrangements on hotkeys: focus (one big), compare (two halves), monitor (grid of four), present (fullscreen).
- **Window switching.**
  Alt+Tab is the slow way. App Expose / Mission Control / WM focus keys / searchable switchers are faster.
- **Rules and automation.**
  Auto-assign apps to desktops, auto-size dialogs, remember layouts per display. Configure once, benefit always.
- **Multi-monitor strategy.**
  Primary for focus work, secondary for reference/comms. Consistent assignment beats ad-hoc dragging.

## Practical workflow

1. **Audit your layouts.**
   Notice your 4-6 recurring arrangements for a week. Those become your hotkey layouts.
2. **Learn snap basics.**
   OS built-in halves/quadrants via hotkey. Use exclusively for a week until dragging feels archaic.
3. **Set up custom zones.**
   If ultrawide or multi-monitor: design zones around real workflows (editor+terminal+browser, etc.).
4. **Assign hotkeys.**
   Each core layout on a memorable hotkey. Practice until arranging is reflex.
5. **Configure virtual desktops.**
   2-4 desktops with roles; auto-assign chat/email to the comms desktop so they stop invading focus.
6. **Set app rules.**
   Dialogs float, terminals tile, video calls go to comms desktop. Automate the predictable.
7. **Learn fast switching.**
   Window switcher beyond Alt+Tab: expose-style overview or WM focus keys for the current context.
8. **Refine monthly.**
   Which layouts do you actually use? Which hotkeys are forgotten? Prune and adjust.

## Common pitfalls

- **Dragging everything manually.**
  Pixel-dragging windows in 2026. Layouts exist; the drag habit is pure overhead.
- **One desktop chaos.**
  30 windows on one desktop instead of contexts on virtual desktops. Finding anything becomes archaeology.
- **Too many layouts.**
  12 custom zones, 6 used never. Design for the 4-6 real arrangements; delete the aspirational ones.
- **No hotkeys learned.**
  A tiling tool used only via mouse menus. The hotkeys are the product — learn them.
- **Fighting the tool.**
  Forcing a tiling WM to behave like floating (or vice versa). Choose the paradigm matching your work; commit.
- **Ignoring multi-monitor.**
  Laptop + monitor used as mirrored/duplicated instead of extended with roles. Assign roles per display.
- **Layout amnesia.**
  Rebuilding the same arrangement every morning. Save layouts, auto-restore, or script the morning setup.
- **Dialog tiling pain.**
  Tiny dialogs tiled into grids. Float dialogs and popups — rules should exempt them automatically.
