# Alfred Pro

## Overview

Alfred is the veteran macOS launcher: blazing file/app search, clipboard history, text snippets, and — with the Powerpack — visual workflows.

Workflows are the superpower: drag-and-drop automation connecting hotkeys, keywords, scripts, and actions without writing an app.

Pro usage: Alfred-first launching, workflows for frequent multi-step tasks, snippets for repeated text, clipboard history as memory.

## When to use

- Setting up Alfred (with or without Powerpack) as the Mac command layer
- Building workflows for frequent multi-step tasks
- Using clipboard history and snippets to eliminate re-typing
- Speeding up file navigation and actions with Alfred
- Migrating from Spotlight to a keyboard-first launcher

## Core concepts

- **Blazing search.**
  Apps, files, folders, contacts, calculations, dictionary, system commands — one input field, instant results, learning your habits.
- **Workflows (Powerpack).**
  Hotkey/keyword triggers -> filters, scripts (bash, Python, JS), and actions (open, notify, copy). Automate anything repeatable.
- **Clipboard history.**
  Text, images, file lists — searchable, persistent. Merge multiple clips, paste as plain text. Your copy memory.
- **Snippets.**
  Type-to-expand text: `!addr` -> address, `;sig` -> signature. Auto-expansion plus a searchable snippet viewer.
- **File actions.**
  Select a file, act: open with, move, copy path, attach to email, reveal. File operations without Finder-diving.
- **Custom searches.**
  Keyword searches for your frequent sites: docs, tickets, repos. `gh <query>`, `jira PROJ-123` — site search from the keyboard.
- **Themes and appearance.**
  Make it yours, but keep it fast: minimal themes, instant show/hide. The launcher should feel like thought.
- **Powerpack features.**
  iTunes/Mini player control, 1Password integration, terminal/shell integration, contacts and dictionary deep access.

## Practical workflow

1. **Take over Cmd+Space.**
   Alfred on the prime hotkey, Spotlight's binding disabled or moved. One launcher, full commitment.
2. **Learn search week one.**
   Apps, files, calculations, clipboard paste. Alfred-first for a week until the Dock feels distant.
3. **Enable clipboard history.**
   Turn on, set sensible history length, verify password-manager exclusion. Learn the viewer hotkey cold.
4. **Build a snippet library.**
   Your 15-20 most-typed texts: addresses, intros, replies, code boilerplate. Prefix convention (`;` or `!`) to avoid accidents.
5. **Create 3 workflows.**
   Real repeated tasks: file-and-rename downloads, start focus session, search across your tools. Start simple, iterate.
6. **Add custom searches.**
   Your 5-10 most-searched sites as keyword searches. Turns the address bar into a memory.
7. **Learn file actions.**
   File selected -> actions menu. Moving, copying paths, opening-with — all without touching Finder.
8. **Back up preferences.**
   Alfred preferences sync via Dropbox/iCloud or manual export. Workflows are work — don't lose them to a reinstall.

## Common pitfalls

- **Spotlight + Alfred split brain.**
  Two launchers, neither reflexive. Commit to one for launching.
- **Workflows for one-offs.**
  Building elaborate workflows for tasks done twice a year. Automate the frequent; do the rare manually.
- **Snippet prefix collisions.**
  Prefixes that expand inside normal typing. Use distinctive prefixes (`;`, `!`, `,,`) and test in context.
- **Ignoring file actions.**
  Using Alfred only to launch apps wastes its file superpowers. The action menu is the file fast path.
- **No workflow backups.**
  Hours of workflow building lost to a dead drive. Sync preferences; export critical workflows.
- **Over-triggers.**
  A hotkey for everything creates conflicts and forgetfulness. Hotkeys for the vital few; keywords for the rest.
- **Default theme squinting.**
  Tiny default text you'll tolerate forever. Spend 5 minutes on a readable theme — you stare at this hundreds of times daily.
- **Powerpack-less workflows envy.**
  Free Alfred is still an excellent launcher + clipboard + snippets. Upgrade when workflows would pay for themselves.
