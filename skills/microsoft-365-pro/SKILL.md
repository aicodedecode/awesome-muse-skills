# Microsoft 365 Pro

## Overview

Microsoft 365 is the enterprise productivity standard: Outlook, OneDrive/SharePoint, Teams, and the Office apps — deeply integrated.

Pro users exploit the integration: @mentions across apps, Teams-SharePoint file unity, Outlook rules + Focused Inbox, Excel power features.

This skill covers the cross-app workflows and settings that turn M365 from 'corporate default' into a genuinely fast environment.

## When to use

- Working daily in Outlook/Teams/Office for work or school
- Speeding up email, document, and meeting workflows in M365
- Organizing SharePoint/OneDrive so teams can find files
- Excel power use: formulas, PivotTables, Power Query
- Administering M365 basics for a small team

## Core concepts

- **Outlook power use.**
  Rules + Quick Steps, Focused Inbox trained, keyboard shortcuts, categories + search folders, delayed delivery, @mentions in mail.
- **OneDrive vs. SharePoint.**
  OneDrive = personal work files. SharePoint = team-owned libraries. Teams files live in SharePoint — know where things actually are.
- **Teams fluency.**
  Channel discipline, chat vs. channel posts, @mentions and tags, file tabs, meeting options (lobby, roles), together mode optional.
- **Word mastery.**
  Styles (not manual formatting), Navigation pane via headings, Track Changes + comments for review, templates, AutoText/quick parts.
- **Excel power features.**
  Tables (structured refs), PivotTables, XLOOKUP, Power Query for data shaping, conditional formatting, data validation.
- **PowerPoint efficiency.**
  Slide Master for consistency, Designer ideas sparingly, presenter view + notes, morph for smooth transitions, templates enforced.
- **OneNote organization.**
  One notebook per area, sections per topic, pages per note; tags for action items; search across everything (including handwriting/image text).
- **Search across M365.**
  Microsoft Search spans mail, files, people, Teams. Learn query habits; it beats folder archaeology in SharePoint.

## Practical workflow

1. **Configure Outlook.**
   Rules for noise, Quick Steps for repeats, Focused Inbox trained, shortcuts learned, signature + delayed send on.
2. **Sort out storage.**
   Personal work in OneDrive; team files in SharePoint libraries/Teams. Stop emailing attachments — share links.
3. **Set up Teams norms.**
   Channel naming convention, when to chat vs. channel, @mention etiquette, file tab usage. Write the norms down.
4. **Learn Excel's power tier.**
   Tables, XLOOKUP, PivotTables, Power Query basics. These four cover 90% of 'Excel wizardry' people ask for.
5. **Template Word/PowerPoint.**
   Corporate templates with real Styles and Slide Masters. Kill manual formatting with fire (or with Styles).
6. **Organize OneNote.**
   Notebook-per-area structure, consistent section naming, tag action items, weekly page triage.
7. **Secure the account.**
   MFA enforced, review app permissions, check sign-in activity. The account holds email + files + identity.
8. **If admin: basics.**
   Licenses, groups/Teams provisioning, MFA enforcement, retention/DLP policies, SharePoint sharing defaults restrictive.

## Common pitfalls

- **Emailing attachments.**
  Version chaos via inbox. Share OneDrive/SharePoint links with permissions — one file, current always.
- **SharePoint sprawl.**
  Nested libraries with no naming convention. Agree structure once; enforce kindly; archive dead sites.
- **Manual Word formatting.**
  Direct formatting everywhere instead of Styles. One style change then costs hours instead of seconds.
- **Excel as database.**
  10,000-row 'databases' with no tables, no validation. Tables + Power Query or an actual database.
- **Teams channel chaos.**
  Everything in General, @channel for trivia. Channel discipline + mention etiquette or Teams becomes noise.
- **No MFA.**
  Corporate email + files + Teams without MFA. The single most preventable breach vector.
- **Ignoring search.**
  Clicking through SharePoint trees instead of searching. Microsoft Search is the fast path — learn it.
- **Meeting without options set.**
  Lobby off, everyone presenter, chaos. Set meeting options for external/large meetings every time.
