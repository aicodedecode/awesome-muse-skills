## Overview

Custom illustration gives brands a visual voice stock imagery never can:
distinctive, ownable, and
emotionally precise. This skill covers illustration for product and brand
contexts — developing a
consistent style, composing scenes that communicate, and building illustration
systems that scale
across a team or product.

## When to use

- Developing an illustration style for a brand or product

- Creating spot illustrations, hero art, or editorial images

- Building an illustration library or system

- Briefing and art-directing illustrators

- Choosing between custom illustration and stock/AI imagery

## Core concepts

- - - **Style is a set of decisions.** Every illustration style is defined by:
  line (weight, presence,
  quality), shape language (geometric vs organic), color (palette size, flat vs
gradient), texture,
  perspective, and character proportions. Document these and the style becomes
repeatable.
- - - **Concept before rendering.** The idea carries the illustration.
  Thumbnails exploring 3-5
  concepts beat one beautifully rendered obvious idea. What's the visual
metaphor? What's the story
  in one frame?
- - - **Composition guides the eye.** Rule of thirds, leading lines, focal point
  with supporting
  elements, generous negative space. The viewer should land on the key element
in under 2 seconds.
- - - **Consistency across pieces.** Same line weights, same palette, same
  character construction,
  same level of detail. An illustration library where each piece looks like a
different artist is a
  failed system.
- - - **Spot vs scene vs hero.** Spot illustrations (small, simple, one idea)
  for UI empty states and
  accents; scenes for storytelling; hero art for emotional impact. Match
complexity to context — UI
  spots must read at small sizes.
- - - **Inclusive representation.** Diverse skin tones, body types, ages,
  abilities, and contexts —
  done thoughtfully, not as tokenism. Build diversity into character libraries
from the start.

## Practical workflow

1. 1. 1. **Define the style.** Based on brand personality: choose the
   line/shape/color/texture
   decisions. Create 2-3 style explorations at different complexity levels; pick
one and document
   the rules.
2. 2. 2. **Build the foundations.** Color palette (limited — 5-8 colors),
   character construction guides
   (proportions, faces, poses), common objects and environments. These are the
system's atoms.
3. 3. 3. **Thumbnail concepts.** For each brief: 3-5 rough thumbnails exploring
   different metaphors and
   compositions. Get concept approval before rendering — reworking a sketch
takes minutes, reworking
   finals takes days.
4. 4. 4. **Refine the chosen direction.** Tight sketch → color → detail. Check
   at actual usage size
   throughout (that hero will also appear as a thumbnail).
5. 5. 5. **Build the library.** Organize by category (people, objects, scenes,
   spots), with consistent
   naming. Include variations (skin tones, poses) where the system supports it.
6. 6. 6. **Write usage guidelines.** Where illustrations go, sizing rules, what
   not to do (don't
   stretch, don't recolor, don't combine styles), and how to request new pieces.
7. 7. 7. **Plan for scale.** Template files, documented styles, and either
   training for team members or
   a clear briefing process for external illustrators.

## Common pitfalls

- - - **Style drift.** Each new illustration subtly different until the library
  is incoherent. The
  style guide exists to prevent this — enforce it.
- - - **Over-detailing small illustrations.** Intricate scenes that become mud
  at UI sizes. Design
  spots to read at 48px; simplify ruthlessly.
- - - **The generic tech illustration.** Faceless purple people floating with
  oversized phones — the
  cliché of the 2020s. If your illustrations are interchangeable with every SaaS
company, the style
  has failed its job.
- - - **No concept.** Pretty rendering of an obvious or confusing idea. Spend
  half the time on what to
  draw, not how.
- - - **Inconsistent characters.** Same "character" with different proportions
  across pieces breaks
  believability. Construction guides aren't optional.
- - - **Ignoring context.** A detailed hero illustration crammed into a 200px
  card, or a tiny spot
  lost on a full-bleed page. Design for the actual placement.
