# Data Broker Removal

Data brokers and people-search sites publish names, addresses,
phone numbers, relatives, and more, assembled from public records
and each other. Removal is unglamorous, repetitive work: find the
listings, file the opt-outs, prove each one landed, and re-check,
because listings come back. This skill runs that loop in an
organized way the user can audit.

## Principles

- **The user directs their own data.** Every opt-out is filed in
  the user's name, for the user's own information. Never file for
  someone else without their clear say-so.
- **Minimum disclosure to remove disclosure.** Opt-out forms ask
  for just enough to find the listing. Give what the form needs
  to match the record, and nothing more. Never give a broker a
  government ID number, a full date of birth, or payment details
  to complete a free opt-out; if a broker demands that, stop and
  tell the user instead.
- **Verify, never assume.** A submitted opt-out is not a removed
  listing. Removal is proven by re-searching the site and finding
  the listing gone, or by the broker's written confirmation plus
  a clean re-search.
- **Keep the ledger.** Every broker, listing URL, action, date,
  and verification result goes in one running record the user can
  read. Memory is not a tracking system.

## Step 1: Inventory the exposure

1. Search the major people-search and broker sites for the user's
   name, plus name and city, and name and phone number. Record
   every live listing: site, exact listing URL, and what it shows
   (address, phone, relatives, age range).
2. Include name variants the user actually appears under (maiden
   or former names, initials, common misspellings the sites use).
3. Group the results: sites owned by the same parent company
   often share one opt-out or suppression system. One filing can
   cover several brands; check the parent company's suppression
   page before filing site by site.

## Step 2: File opt-outs and suppressions

Work the inventory in order, biggest exposure first (listings
showing a home address or phone number outrank name-only ones).

For each broker:

1. Find its official opt-out or privacy page. Prefer a suppression
   tool that removes the record from all of the company's
   products at once over a single-listing deletion.
2. Complete the opt-out with the minimum matching data. Many
   brokers email a verification link to finish the request; that
   link goes to the user's own email and the user completes it,
   or confirms to you that it arrived.
3. Record: broker, date filed, listing URL, expected removal
   window (brokers commonly say days to a few weeks), and how
   completion will be verified.
4. Never pay a broker to remove a listing, and never sign the
   user up for a paid removal service, without their explicit
   decision on that specific service. Free opt-outs are the
   default path.

## Step 3: Verify removals

- When each broker's stated window passes, re-search the site the
  same way the listing was found. Mark the entry removed only
  when the listing is actually gone.
- If it is still live after the window, file once more and note
  the repeat. A broker that ignores two filings gets flagged to
  the user with the evidence, along with the formal options
  (privacy-rights request under their state law, regulator
  complaint) for them to decide on.

## Step 4: Re-check on a cadence

- Brokers re-ingest public records, so listings return. Re-run
  the inventory search about every three months and file fresh
  opt-outs for anything that reappeared.
- Reduce the source flow where the user wants to: unlisted
  number where their carrier allows it, a mailing address that is
  not the home address for public filings, and care with loyalty
  and warranty registrations that feed broker data.

## What this skill does not do

- It does not remove public records themselves (court, property,
  voter records); it removes broker republication of them, and it
  should say so plainly when the user asks.
- It does not touch other people's listings, post anything
  publicly, or contact brokers by phone with the user's personal
  details beyond what a specific opt-out the user approved needs.
- It does not guarantee a clean slate. The honest deliverable is
  a shrinking, verified ledger, not a promise that nothing exists
  anywhere.
